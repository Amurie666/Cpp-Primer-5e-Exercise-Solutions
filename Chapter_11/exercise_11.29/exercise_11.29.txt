In general, lower_bound(k) returns the first element with key greater than or equal to k, otherwise it returns off-the-end iterator. Similarly, upper_bound(k) returns the first element strictly greater than k, otherwise it returns off-the-end iterator. As a consequence, if no element with the key k exists in the container, then lower_bound will return the first element with key strictly greater than k (or off-the-end iterator otherwise), implying that upper_bound(k) = lower_bound(k). The equal_range() function returns a pair holding lower_bound(k) as first and upper_bound(k) as second.
