Setting the parameter as Folder would just save the message into a soon-to-be deleted copy of the originally passed Folder argument. Setting it as const Folder& would result in a call to a non-const member function through msgs.insert(&msg), which is an error. Furthermore, and because the folders set is defined for Folder* element type in the Message class, we cannot convert const Folder* (returned by &fldr) to plain Folder*.
